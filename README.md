Features`n`n1. **Authentication Flow**:`n   * Forced modal login/signup on first access.`n   * Persistent user sessions stored locally with explicit Sign Out controls.`n`n2. **Meeting Management**:`n   * **Instant Meetings**: Generate unique room IDs dynamically and enter immediately.`n   * **Scheduled Meetings**: Create upcoming meetings mapped to selected dates and times.`n   * **Meeting Tabs & Calendar**: Interactive schedule viewer filtering upcoming, recent, and recorded sessions.`n`n3. **Direct Room Joining**:`n   * Join specific rooms directly via URL (e.g., `/meeting/[id]`).`n   * Join existing meetings using the **Join Meeting** ID prompt on the dashboard.`n`n4. **Responsive Zoom UI**:`n   * Pixel-accurate Zoom navigation sidebar, header controls, date pickers, side panels, and responsive mobile layout.`n`n---`n`n## ??
